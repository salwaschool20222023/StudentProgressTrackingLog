📥 استيراد أسماء الطالبات

الصق أسماء الطالبات هنا، كل اسم في سطر منفصل (بنفس ترتيب كشف الدرجات). سيتم توزيعها تلقائياً على صفوف الجدول بالترتيب من 1 إلى 30.

لنسخ الأسماء من ملف PDF:
  1. افتحي ملف الكشف بصيغة PDF، وحددي عمود الأسماء بالماوس (اسحبي من أول اسم لآخر اسم).
  2. انسخي التحديد (Ctrl+C أو من قائمة الفأرة اليمنى "نسخ").
  3. الصقي النص في المربع أعلاه (Ctrl+V) — إذا كانت الأسماء مرقّمة، لا مشكلة، سيتم تجاهل الأرقام تلقائياً عند الاستيراد.
  4. اضغطي زر "استيراد الآن" لتوزيع الأسماء على الجدول.
لنسخ الأسماء من ملف Excel:
  1. حددي عمود الأسماء في إكسل (بدون خلية العنوان).
  2. انسخي (Ctrl+C) والصقي مباشرة في المربع أعلاه.

📊 إحصائيات المتابعة

⚙️ إعدادات التخزين السحابي

افتراضياً يُحفظ السجل تلقائياً بتخزين سحابي مدمج. يمكنك بدلاً من ذلك ربط السجل بقاعدة بياناتك الخاصة على Supabase.

لإعداد Supabase لأول مرة:
  1. أنشئي مشروعاً مجانياً على supabase.com.
  2. من قسم SQL Editor نفّذي هذا الأمر مرة واحدة لإنشاء جدول التخزين:
create table app_storage (key text primary key, value jsonb);
alter table app_storage enable row level security;
create policy "allow all" on app_storage for all using (true) with check (true);
  1. من Project Settings → API انسخي "Project URL" و"anon public" والصقيهما أعلاه، ثم اختاري "Supabase" من قائمة نوع التخزين واضغطي حفظ.

🔒 دخول السجل

هذا السجل خاص بالمعلمة أ. غادة دياب — يرجى إدخال كلمة السر للمتابعة.
